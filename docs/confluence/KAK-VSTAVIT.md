# Как вставить страницу в Confluence (sberworks)

**Не вставляйте wiki-разметку напрямую в редактор страницы** — она отобразится как обычный текст.

## Способ 1: Insert → Markup (рекомендуется)

1. Создайте или откройте страницу в Confluence.
2. Задайте заголовок страницы: **Куда идти с новым проектом — Центр компетенций** (h1 в теле страницы не нужен).
3. Нажмите **+** (Вставить) → **Разметка** / **Markup**.
4. Выберите тип: **Confluence Wiki**.
5. Скопируйте **весь** файл `kuda-idti-s-novym-proektom.wiki` и вставьте в окно.
6. Нажмите **Вставить** / **Insert**.

## Способ 2: по частям

Если целиком не вставляется, вставляйте блоками через **Insert → Markup → Confluence Wiki**:

1. Блок info + note + первая таблица
2. Вторая таблица (кластер)
3. Нумерованный список + panel
4. Каждый `{expand:...}...{expand}` отдельно

## Если wiki не работает

Используйте `kuda-idti-s-novym-proektom.html`:

1. Откройте HTML-файл в браузере.
2. Выделите всё (Ctrl+A) и скопируйте (Ctrl+C).
3. Вставьте в визуальный редактор Confluence (Ctrl+V).
4. Expand-блоки и цветные панели добавьте вручную через меню **+** → **Развернуть** / **Панель**.

## Частые ошибки

| Проблема | Причина |
|----------|---------|
| Таблица «разваливается» | Ссылки `[текст\|url]` в ячейках — символ `\|` обязателен |
| Вместо жирного — маркированный список | Строка начинается с `*` — в файле метки заменены на `_курсив_` или таблицы |
| Макрос виден как текст | Вставка не через Insert → Markup |
| Статусы не отображаются | Используются эмотиконы `(/)` и `(!)` вместо макроса status |
