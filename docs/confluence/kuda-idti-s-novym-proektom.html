Пошагово: как обратиться с новым проектом

  1. Определите тип запроса — таблица «Быстрый выбор» выше
  2. Откройте страницу команды — ознакомьтесь с зоной ответственности
  3. Создайте задачу в Jira (ссылка в таблице) или напишите координатору
  4. Если запрос комплексный — начните с Проектного направления, они помогут подключить нужные команды

Важно. Ссылки Jira помечены плейсхолдерами CC_AI_*_JIRA — замените на реальные URL проектов в Jira после согласования с координаторами.

Когда обращаться в каждую команду

Блоки «Развернуть» (expand) добавьте вручную через меню Вставить, либо вставьте соответствующие секции из .wiki-файла через Insert → Markup.

Другие кластеры
